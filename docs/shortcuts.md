# Keyboard Shortcuts

LogViewer is built for rapid keyboard navigation during intense debugging sessions.

| Action | macOS | Linux & Windows |
| :--- | :--- | :--- |
| **Open Logs** | ++cmd+o++ | ++ctrl+o++ |
| **Search Filters** | ++cmd+shift+f++ | ++ctrl+shift+f++ |
| **Find in Active Table** | ++cmd+f++ | ++ctrl+f++ |
| **Next Find Match** | ++f3++ / ++enter++ | ++f3++ / ++enter++ |
| **Previous Find Match** | ++shift+f3++ / ++shift+enter++ | ++shift+f3++ / ++shift+enter++ |
| **Toggle Selected Filter(s)** | ++space++ | ++space++ |
| **Next Filter Occurrence** | ++period++ | ++period++ |
| **Previous Filter Occurrence** | ++comma++ | ++comma++ |
| **Go to Timestamp** | ++cmd+g++ | ++ctrl+g++ |
| **Inspect Line Details** | ++cmd+i++ | ++ctrl+i++ |
| **Switch to Main Logs Tab** | ++cmd+1++ | ++ctrl+1++ |
| **Switch to Bug Report Tab** | ++cmd+2++ | ++ctrl+2++ |
| **Switch to Live Logs Tab** | ++cmd+3++ | ++ctrl+3++ |
